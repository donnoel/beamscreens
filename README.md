## 🧭 Overview

Public GitHub Pages site for Beam.

The Beam application source remains in its separate private repository.

## 💎 Core Features

| Feature | What it does |
| --- | --- |
| **Public overview** | Introduce Beam through the project site. |
| **Support** | Provide the published support page. |
| **Privacy** | Provide the published privacy page. |
| **Shared theme** | Use the versioned Don Noel project-site theme. |

## 🚀 Getting Started

This is a GitHub Pages content repository. Start with [the site content](index.md) and [the site configuration](_config.yml). The Beam application is developed in its separate repository.

## 🧠 How It Works

The site uses the shared Jekyll remote theme pinned in `_config.yml`. Public support and privacy pages live alongside the project overview.
